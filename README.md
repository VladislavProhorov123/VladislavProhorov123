## Projects

## Movie App (Fullstack)
Полноценное fullstack приложение на базе TMDB API с авторизацией, базой данных и защитой данных пользователя.

- регистрация и логин пользователей (JWT + bcrypt)
- сохранение пользователей и данных в PostgreSQL (Neon + Prisma)
- защита функционала: незарегистрированный пользователь не может добавлять фильмы в избранное
- работа с TMDB API (фильмы, категории, поиск)
- фильтрация фильмов по категориям
- отдельная страница актера
- просмотр информации об актере (био, фильмы, роли)
- трейлеры фильмов
- информация о бюджете и деталях фильма
- адаптивный UI

**Stack:** React, Node.js, Express.js, TypeScript, Prisma, PostgreSQL (Neon), JWT, Bcrypt, Tailwind

**Ссылка на проект:** [GitHub](https://github.com/VladislavProhorov123/MovieApp)  
**Демо:** [Live Demo](https://movie-app-one-alpha-11.vercel.app/)

## Bouton Akkerman (Commercial Concept Project)
Коммерческий проект для цветочного бизнеса (локальный рынок), реализованный как полноценный frontend + backend прототип.

- 4 полноценных страницы (каталог, заказ, форма, информация)
- каталог товаров с фильтрацией
- формы заказа букета с валидацией
- отправка заявок через формы
- сохранение заказов в базе данных (Supabase)
- адаптивный интерфейс под мобильные устройства
- попытка реализации коммерческого продукта для реального бизнеса

**Stack:** React, Supabase, TailwindCSS
